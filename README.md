# Justdial – Events Module Testing

## Project Overview

This repository contains the manual testing documentation and test artifacts for the Events module of Justdial.

The purpose of this project is to verify the functionality, usability, navigation, search, filtering, and event information displayed in the Events module.

## Project Details

| Attribute | Details |
|---|---|
| Application | Justdial |
| Module | Events |
| Testing Type | Manual Testing |
| Testing Level | System Testing |
| Testing Approach | Functional and UI Testing |
| Environment | Windows Desktop/Laptop |
| Browsers | Google Chrome, Microsoft Edge, Mozilla Firefox |

## Testing Objectives

The main objectives of this testing project are:

- Verify Events module navigation.
- Verify Events page UI elements.
- Verify event search functionality.
- Verify location-based event search.
- Verify event category filtering.
- Verify date-based filtering.
- Verify event listing information.
- Verify event details.
- Verify event images.
- Verify event descriptions.
- Verify contact/call functionality.
- Verify directions/map functionality.
- Verify negative scenarios.
- Verify browser compatibility.
- Identify and document defects.

## Test Case Status

Each test case can have one of the following statuses:

- **Pass** – Actual result matches expected result.
- **Fail** – Actual result does not match expected result.
- **Blocked** – Test execution cannot continue because of an external issue.
- **Not Executed** – Test case has not yet been executed.

## Testing Methodology

The testing process follows these steps:

1. Understand the Events module requirements.
2. Prepare the test plan.
3. Identify test scenarios.
4. Create detailed test cases.
5. Execute the test cases.
6. Record actual results.
7. Mark test status.
8. Report defects.
9. Retest fixed defects.
10. Prepare the final test summary.
